# 道乃久（TaoChronos）投稿图表 · Nature 风格

一套按 Nature Portfolio 图表规范制作的投稿用图表：**5 张主图、3 张扩展数据图（Extended Data）、2 张表**，外加英文图注、
源数据（Source Data）与合规检查报告。所有数值都来自本仓库可复现的数据与运行结果，不含任何虚构或示意数据；需要全量语料
（未随仓库分发）的少数数值转录自 `docs/evals.md`，并在图注与源数据中逐项标明。

- 审阅用合订本：[`TaoChronos_display_items.pdf`](TaoChronos_display_items.pdf)（每张图 + 图注，最后是两张表）
- 投稿用母版：`figures/out/*.pdf`（矢量，文字可编辑，字体已嵌入）；另有 `*.svg` 与 600 dpi `*.png`
- 图注：[`legends.md`](legends.md)（英文，每条 < 300 词）；表格：`tables/tables.docx`（Word 三线表）、`table*.tex`、`table*.md`
- 合规报告：[`figures/out/qc/QC_REPORT.md`](figures/out/qc/QC_REPORT.md)（8 张图全部 PASS）

## 规范对照（Nature 显示项要求）

| 项目 | 本套图表 |
|---|---|
| 尺寸 | 全部为双栏 183 mm 宽，高度 58–128 mm（≤ 170 mm）；按最终印刷尺寸以毫米排版，从未缩放 |
| 格式 | 矢量 PDF 为母版（TrueType 嵌入、文字可选可编辑）+ SVG + 600 dpi RGB PNG |
| 字体 | Arial（汉字逐字回退到 Noto Sans CJK SC）；正文 5–7 pt，面板标号 8 pt 粗体小写 |
| 线宽 | 0.25–1 pt |
| 配色 | Okabe–Ito 色盲友好色板；蓝色标示被检验的变量，其余用灰；无红绿对比、无彩虹色、无渐变/阴影/网格线、无彩色文字 |
| 统计 | 精确 P 值（斜体 P）、检验名称、n、区间定义都写在图注里；小样本同时给出计数（如 82/84） |
| 表格 | 可编辑文本、三线表、无竖线、单位在表头、脚注用 * † ‡ |
| 源数据 | `figures/source_data/` 中每张图所画的每个数值（CSV/JSON） |

## 一键重建

```bash
pip install -e . matplotlib numpy scipy pandas pymupdf python-docx
bash paper/make_all.sh          # 约 7 分钟：源数据（含开放语料上的研究价值复跑）→ 突变矩阵 → 8 张图 → 图注字数 → 合规检查 → 表格
python3 paper/build_preview.py  # 合订审阅本（需要 Chromium）
```

`make_data.py` 会在临时目录里用 `corpus/web` 构建要籍语料库、在演示语料上运行 `taochronos eval`、在要籍语料上运行治学工具；
不需要全量语料，也不读写你的数据目录。

## 需要作者留意与决定的事项

1. **Fig. 4 的数值来自全量语料的运行记录**（`docs/evals.md`）。全量语料不随仓库分发，本次无法复算；若在本机已构建全量语料，
   建议运行 `taochronos eval research_value -o rv_full.json`，可把 Fig. 4 升级为逐主题配对散点图（Nature 审稿人偏好展示个体数据）。
2. **ED Fig. 2 结果有正有负**：在开放要籍语料（全量的约 7%）上，排序相对流行度的优势可复现，但无法与随机区分。是否放入投稿由你决定；
   我建议保留并在正文说明“该基准需要全量语料”，这比不报告更经得起审稿。
3. **实测突变矩阵与 `docs/evals.md` 有两处出入**（图注已按实测撰写）：拆除证据边界检查后，5 条不可能的证据中是 **2 条**通过核验
   （文档写作全部 5 条）；拆除作用域守卫后，工具不再被拒，但**并没有读出被扣留的段落**（作用域视图仍然隐藏它），伪造的 G7 进入日志但
   未进入状态——这是纵深防御的正面证据。是否同步修正文档，请你决定。
4. **金标准由作者构建**，只是回归测试、不是无偏基准；Table 2 与 ED Fig. 1 已把开发集与留出集/真实语料分列。投稿正文需明确说明，
   并建议补充专家标注的留出集。
5. **授权**：笈成整理本未声明授权（ED Fig. 3b 如实以灰色标出）。投稿的数据可用性声明请与 `corpus/web/ATTRIBUTION.md` 保持一致。
6. **未使用 `data/chat-logs/` 的对话记录**：访客同意的是测试期间记录，用于论文需另行知情同意与伦理审批。
7. **目标期刊**：若投 Nature Communications 或 Nature Medicine，双栏宽为 180 mm——把 `figures/nature_style.py` 中
   `WIDTH["double"]` 改为 180 后重跑 `make_all.sh` 即可；若投 Scientific Data（数据描述论文），图的叙事应改为资源文档型。
8. 图中文字以英文为主，汉字只用于古籍原文、书名与术语（均已嵌入字体）；若编辑要求去掉汉字，可在各图脚本中替换为拼音。
