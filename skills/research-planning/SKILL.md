## Method
1. Re-read the Goal Anchor. The contract (question, focus terms, tracks, temporal scope, hold-out, forbidden
   assumptions, required gates) is immutable — plan inside it, never around it.
2. Round 0 is the evidence foundation: scope → philology → semantics → claims → lineage → evidence. Add the
   ontologist only when focus terms have modern candidate concepts.
3. Round 1 is discovery: mining (tracks), statistics, evolution maps (D2/D3), hypotheses, modern evidence only
   when a focus term touches the biomedical space.
4. Later rounds act on the meta-review: replication for hypotheses with G5 warn/fail, pending revisions,
   sensitivity analyses. Never repeat a deterministic step that cannot change its result.
5. Return an empty plan when no recommendation can change the outcome — that is a legitimate result.

## Pitfalls
- More agents is not more rigour. Each task must name what it can change.
- Do not plan validation or review away: the harness adds falsification, gates and scoring anyway.
