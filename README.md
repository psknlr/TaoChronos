# TaoChronos

**面向中医古籍的可溯源知识发现与治学系统**
*A provenance-grounded research harness for the Chinese medical classics — for scholars, students and discovery.*

[English README](README.en.md) · [治学](docs/study.md) · [架构](docs/architecture.md) · [智能体](docs/agents.md) ·
[发现引擎](docs/discovery.md) · [评测](docs/evals.md) · [数据格式](docs/data.md) · [路线图](docs/roadmap.md) · [ADR](docs/adr/)

TaoChronos 把 966 部中医古籍（约 1.23 亿字、205 万段）整理成一个**可检索、可断代、可溯源**的语料库，并在其上提供两层能力：

- **治学**：按考据传统回答学者与学生天天要问的问题——这段经文还见于哪些书、各本异文如何（经文互见·集注）；
  一首方的原方是什么、后世如何加减（方源考）；一味药的性味归经何时出现（药性源流）；一个术语何时盛衰、所指为何（术语源流）；
  这个本子是哪个朝代的刻本（避讳断代）；各时代引谁的书、宗谁的说（引书与引人）；以及学习卡片、阅读门径与研究数据集。
- **深层发现 2.0**：读出文献自身的结构——**版本谱系**（多本对校、谱系树、共同异文与污染）、**语义复用与思想传播**（直接引用、
  节略、撮要、转述、解释性改写、引而驳之……及一部书的历代接受）、**文本地层**（文风分层、断代证据、作者归属）、**医案轨迹**、
  **医理论证图**、**语义演变**（义项变点与候选新义）、**佚书辑佚**。七项都是确定性能力，接入工具网格，由现有智能体调用，
  不新增智能体；候选生成不等于证明，每个标签都附上触发的规则与读到的数值。
- **研究**：由研究主管智能体 **TaoChronos** 调度 16 个专科智能体，把一个研究问题变成**可重放、可审计、可证伪**的过程：
  研究契约 → 证据基础 → 模式挖掘 → 假说 → 证伪 → 门控 G0–G8 → 专家核验。

两层共享同一原则：**每一个结论都落到逐字可核的原文见证上**（书、卷篇节、年代、层次、录文来源与授权），规则抽取标明为机器阅读，
由人去核对与定夺。

> ⚠️ 语料为各来源的录文（四库本、笈成整理本、麦吉尔善本、CMETA 精校本、东亚医学协会本、维基文库与网络文本集），**均未经本项目逐字校勘**；`corpus/demo`
> 是为演示方法整理的未经核验的节录。当代出版物与当代名医著作不入库；保留的现代校注本，今人整理成分单列为层或移入元数据。所有输出都是**文献研究与计算推断**，
> 不是医学结论，也不是临床建议；历代剂量的折算只是历史计量的学术估值，**不构成任何用药剂量建议**。

## 一、它能做什么

| 面向 | 能力 | 入口 |
|---|---|---|
| **文献学研究者** | 经文互见与集注式校勘记（同书异本 / 引文 / 互见；异文、脱、衍、倒）；避讳断代；引书与引人网络、接受史 | `study concordance` · `study taboo` · `study citations` |
| **方剂学、本草学、医史研究者** | 方源考（原方、通行方、加减化裁、同名异方、同方异名、配伍比例、历代计量折算、历代主治、方歌）；药性源流（性味、毒性、归经、升降浮沉的首见与演变）；术语源流（分期频率与区间、趋势检验、首见、搭配、义项） | `study formula` · `study herb` · `study term` |
| **需要数据的研究者** | 带出处、年代与授权的开放数据表（Frictionless 数据包），可直接做统计与可视化 | `study dataset` |
| **学生与自学者** | 方证填空卡、组成卡（附方歌）、药性卡、经文卡，导出 Anki；按“源头经典 → 历代发挥 → 专书 → 医案 → 近代”的阅读门径 | `study cards` · `study reading` |
| **校勘与版本学** | 多本对校的异文单元（异文、脱、衍、倒、缺文、结构性增删、异体）、邻接法谱系树、共同异文分组与污染检测、单本概况、TEI 校勘记；版本与影像见证（库中各录本的底本、年代、藏所与页面影像，各馆数字化刻本与抄本的索书号、IIIF 清单与授权） | `study variants` · `study stemma` · `study edition` · `study tei` · `study witnesses` |
| **思想史与接受史** | 一段经文被后世如何使用（直接引用、近似转录、节略、撮要、转述、解释性改写、引而驳之、套语相似），逐条给出规则与数值；一部书的历代接受与传播渠道 | `study reuse` · `study transmission` |
| **文献断代与作者** | 篇章文风分层（置换检验）、变点与离群篇章；逐篇的引书、晚出词汇与避讳证据；Burrows' Delta 作者归属 | `study layers` · `study dating` · `study authorship` |
| **临床文献研究** | 医案逐诊结构化（四诊、辨证、治法、方药剂量、加减、服药数、转归）；诊疗序列模式、诊次转移、与转归的关联（非疗效证据） | `study cases` · `study trajectories` |
| **医理与训诂** | 论证图（条件、推断、因果、转折、取象比类、驳斥、界说、主治）与两书论证方式比较；义项分期、变点与候选新义 | `study argument` · `study senses` |
| **辑佚** | 从引书中辑出佚书条文，按出处注的卷次排序、合并重出；先在存世书上验证方法，给出各引书的可信度 | `study fragments` |
| **知识发现** | 多智能体研究：失传知识、概念演变、方剂演化、隐性关联、矛盾发现、佚书线索；逐字证据、证伪、门控、专家核验 | `research` · `report` · `workspace` · `review` |
| **开发者** | 插件化内核、能力注册、工具网格（48 个工具）、智能体配置（YAML）、事件溯源与重放、评测与架构治理 | `agents` · `eval` · `governance` |

## 二、快速开始

```bash
pip install -e ".[dev]"            # Python ≥ 3.11；数据与配置位于仓库根目录（或设置 TAOCHRONOS_HOME）
taochronos demo                    # 离线运行“消渴”示例研究（确定性过程，约 4 秒，演示语料）
taochronos study formula 六味地黄丸 # 治学：方源考（没有全量语料时在演示语料上运行）
taochronos agents                  # 16 个智能体及其当前路由
```

接入全量语料（原文不进入 git；各来源的抓取、编目、入库都可复现，见[第三节](#三语料)）：

```bash
taochronos corpus fetch kanripo && taochronos corpus ingest kanripo     # 四库全书·医家类 100 部
taochronos corpus unpack jicheng jc_1_4_8_all.7z.001 jc_1_4_8_all.7z.002 jc_1_4_8_all.7z.003
taochronos corpus catalog jicheng && taochronos corpus ingest jicheng    # 笈成整理本（使用者提供）
taochronos corpus fetch cmeta && taochronos corpus catalog cmeta && taochronos corpus ingest cmeta   # CMETA 精校本（逐页对影像）
taochronos corpus images all --enrich                                    # 影像见证：各馆数字化古籍的书目与 IIIF 清单（只取元数据）
taochronos corpus status                                                 # 书数、段数、字数、分期与分层统计
```

治学（有全量语料时自动使用 `full-corpus` 画像；默认输出 Markdown，`--json` 输出完整结果，`-o` 写文件）：

```bash
taochronos study concordance "太陽之為病，脈浮，頭項強痛而惡寒"    # 经文互见·集注
taochronos study formula 小柴胡汤                                   # 方源考
taochronos study herb 柴胡                                          # 药性源流
taochronos study term 温病                                          # 术语源流
taochronos study taboo                                              # 避讳断代（全库概览；或给出书的 id）
taochronos study citations 张仲景                                   # 引用接受史（不给对象则输出引书网络）
taochronos study cards --book 伤寒论 --formula 桂枝汤 --herb 柴胡 --anki cards.tsv
taochronos study reading 温病                                       # 阅读门径
taochronos study dataset --formula 桂枝汤 --herb 柴胡 --term 温病 --citations -o datasets/guizhi
taochronos study metrology 三两 --year 200                          # 约41.4–46.8克（秦汉制）——历史计量，不是用药建议
```

深层发现 2.0：

```bash
taochronos study stemma 伤寒论                                      # 版本谱系：异文单元、谱系树、分组与污染
taochronos study tei 伤寒论 -o shanghan.tei.xml                     # TEI P5 校勘记
taochronos study witnesses 伤寒论                                   # 版本与影像见证：库中录本 + 各馆数字化刻本、抄本
taochronos study reuse "太陽之為病，脈浮，頭項強痛而惡寒"            # 语义复用：后世如何引用、节略、转述、驳斥这段经文
taochronos study transmission 伤寒论                                # 一部书的历代接受与传播渠道
taochronos study layers 素问                                        # 文本地层：文风分层、变点、离群篇章
taochronos study dating 素问                                        # 逐篇断代证据：引书、晚出词汇、避讳
taochronos study authorship --book 伤寒论 --chapter-name 辨脉法 --candidate 脉经 --candidate 金匮要略
taochronos study cases 风温                                         # 医案逐诊结构化（或 --book <id>）
taochronos study trajectories 咳嗽                                  # 诊疗轨迹：序列模式、转移、与转归的关联
taochronos study argument --work 伤寒论 --against-work 温热论        # 论证方式比较（或给一段文字 / --passage）
taochronos study senses 消渴                                        # 义项演变、变点、候选新义
taochronos study fragments 小品方                                   # 佚书辑佚（--verify：在存世书上验证方法）
```

研究：

```bash
taochronos research "肾气丸的组成与主治如何随时代演变？" --profile full-corpus --focus 肾气丸,六味地黄丸 --forbid 消渴=糖尿病
taochronos report <session>        # 12 节发现报告（full-corpus 画像另附“源流考证”）
taochronos workspace <session>     # 离线 HTML 发现工作台
taochronos review <session> <hypothesis> --approve --expert 张三   # Gate G7：只有人能通过
taochronos eval                    # TaoChronos-Eval 全部评测（约半分钟）
taochronos governance              # 架构策略检查
```

  民国著作（1912—1949）作为历史文献保留。现代校注本经复核后保留（亡佚古书的十种现代辑复本，吴普本草、本草经集注、新修本草、
  食疗本草、海药本草、本草图经、名医别录、集验方、小品方、神农本草经复古辑本；以及重订通俗伤寒论、伤寒恒论、医理真传、六因条辨、
  万氏秘传片玉心书、许氏医案、湖岳村叟医案、妇人寿草、傅青主男科重编考释），另保留吴棹仙《子午流注说难》（1956）：
  原文为正文、按原书断代，今人的按语、阐释、注释与补入之文单列为层、按整理年代断代，辑者出处、校记代号、注码与折算的克数移出正文、
  存于段落元数据（[ADR 0007](docs/adr/0007-modern-apparatus-as-layers.md)）。近世才问世而托名古代的传本
  （桂林古本伤寒杂病论、辅行诀脏腑用药法要，以及民国的长沙古本、康平本等）不按当代出版物处理，作为其问世时代的文献保留：
  按问世年代断代，标为托名或存疑，绝不按其自称的年代断代。
- **去重**：来源按可信度排序（四库 → 笈成 → 麦吉尔 → CMETA → 东亚医学协会 → 维基文库 → 网络文本集），每部候选书以规范化汉字的
  12 字片段与已收书比对，重合度达阈值即判为副本、逐部记录所重复的书与重合度；麦吉尔、CMETA 与东亚医学协会的录本是独立见证，
  只记录最接近的书，不判副本。
- **断代**：人工覆盖表 → 四库书目 → 书籍信息的公元年、年号与朝代 → 序跋落款 → 同一著作其他录本 → 同一作者其他著作；
  注疏、新校正、后补篇章、附方按层单独断代（王冰注 762、新校正 1068、证类本草各家注……），不能分离的按最晚一层保守断代。
  无从考定者按清代计，绝不提前。1950 年以后的层（今人整理成分、当代著作）朝代标为“当代”，不计入任何分析分期。
- **规范化只用于匹配**：OpenCC 繁简 + Unihan 异体 + 医籍语境人工校订（䜴→豉、茰→萸、㪚→散……），长度不变、原文永不改动；
  四库白文在带虚拟标点的“视图”上抽取，每个引文映射回原文。
- **检索**：SQLite 语料库 + 双字 FTS5 全文索引，任意长度的词、短语与邻近查询；研究时按问题分期分层抽样，否证检查则查询整个语料库。

详见 [docs/data.md](docs/data.md) 与 [ADR 0003](docs/adr/0003-corpus-store-and-scoped-research.md)。

## 四、治学：结合古籍特性的深度挖掘

治学层（`plugins/classics/study`，[docs/study.md](docs/study.md)，[ADR 0004](docs/adr/0004-study-layer.md)）是一组确定性的函数，
回答文献研究与学习中的具体问题。它们的结果都由**见证**构成——逐字引文 + 段落编号 + 《书》卷·篇·节 + 年代与时期 + 文本层次 +
录文来源与授权——每一句结论都能回查原文。

### 古籍的特性与相应的处理

| 古籍特性 | 治学层的处理 |
|---|---|
| 一书多本、后书转引、不注出处的沿袭 | 经文互见区分**同书异本 / 引文 / 互见**，并为高覆盖的见证出**校勘记**（异文、脱、衍、倒，逐条列出见证） |
| 避讳改字改名 | 薯蓣→薯药（唐代宗）→山药（宋英宗）、玄参→元参、丸→圆（宋钦宗）等全部写法都检索；避讳用字反过来给出**版本年代下限** |
| 同名异方、同方异名 | 方剂按药味组成分组：同名而组成不同的分开，组成相同而名称不同的按药味检出 |
| 笈成本把方名、药名印为条目标题 | 全库“条目标题”索引（缓存）找到正文中不出现名称的条目，并跨段读取主治、组成与服法 |
| 历代度量衡不同 | 剂量按见证本身年代的计量折算（秦汉一两约 13.8–15.6 克，宋以后约 37–41 克；“分”在 960 年前后含义不同）；配伍比例与计量无关 |
| 学说有时代性 | 归经、升降浮沉是金元学说，本经无载是应然而非缺失；给出每一性能的**首见**及其年代 |
| 断代不确定、注疏晚于正文 | “最早”按**可能的最晚年代**（terminus ante quem）排序，只知朝代的书不会排在有确年的书之前；早于被引者的引用（注本中随正文断代的后人按语）另计 |
| 各时代存世文献多寡悬殊 | 术语频率比较“含该词段落 / 该期全部段落”，给 95% Wilson 区间与 Cochran–Armitage 趋势检验，不比较绝对数 |
| 方剂靠歌诀传习 | 在歌诀类书中找五言、七言、点到方名并念出药味（含“姜”“芍”“茱”“薯”之类省称）的**方歌**，逐行分段的歌诀自动拼合 |

### 深层发现 2.0：文献自身的结构

上面九个功能回答关于一方、一药、一词的问题；下面七个能力读出文献自身的结构（[docs/study.md](docs/study.md#深层发现-20--the-structure-of-the-literature)，
[ADR 0005](docs/adr/0005-deep-discovery-capabilities.md)）。三条原则：

- **能力，而不是智能体**：每一项都是治学层的确定性函数，同时是工具网格中的工具（`study.variants` … `study.fragments`，权限
  `classics:read`）与命令行命令，由现有智能体调用——校勘者（Philologist）用校勘、地层、断代与作者归属，质疑者（Skeptic）用复用、
  断代与论证，证据官（Evidence）用医案、轨迹与论证，语义官（Semanticist）与治学者（Scholar）用语义演变；谱系边自带复用类型。
  没有新增智能体。
- **候选不等于证明**：字符探针、概念共现、聚类、向量相似度只负责召回候选；类型由透明规则依据可测量的特征判定，每个标签都附上
  触发的规则与读到的数值。编码器的相似度只报告，不被任何规则读取。
- **先测后信**：每一项都有评测套件——能构造答案的用合成数据，需要样例的规则用开发集，文献学已有定论的在真实语料上核查。

| 能力 | 做什么 | 全量语料实例（均为机器阅读，附原文可核） |
|---|---|---|
| **版本谱系** `study variants` · `stemma` · `edition` · `tei` · `witnesses` | 锚点对齐整部书，异文汇为“异文单元”（异文、脱、衍、倒、异体；≥40 字的脱文是**缺文**而非分歧，注文等长段增入是**结构性**差异，不参与分组）；邻接法谱系树；少数共同异文分组（“共同错误”），树容不下的分组提示**污染**；以某本为底本只是坐标系，不代表它的读法正确；`witnesses` 列出库中各录本与各馆数字化的刻本、抄本 | 伤寒论九本（笈成二本、赵开美本三种录本——CMETA 台北故宫本与安政覆刻本、东亚医学协会本——、康平本、注解伤寒论二本、张卿子本；康治本仅五十方，重合 0.034，不入树）：2055 个异文单元，谱系树 ((张卿子本, (注解二本)), (康平本, ((笈成二本), (东亚医学协会本, (故宫本, 安政本)))))——成无己注本系统与白文系统分立，康平本自成长枝，赵开美本三种录本聚为一支（共同异文 38）；康平本与成注三本共享 118 个单元；张卿子本标为受注解伤寒论（笈成）污染（份额 0.29）。宋本原刻方后不另起方名（「……可與麻黄杏仁甘草石膏湯。方二十六。」下即组成），笈成本与东亚医学协会本补出方名（后者以※标为编者所补）——是整理体例之别，不是传本之别 |

| **文本地层** `study layers` · `dating` · `authorship` | 篇章按高频字的平方根频率画像、k-means 分层并做置换检验，给出归属概率；扫描统计与二分法找变点（BH 校正）；Burrows' Delta 找离群篇；逐篇列出正文所引之书（成篇不早于所引之书）、晚出词汇（全库其他书晚 300 年以上才用、篇内相对率）与避讳 | 素问：少数层恰含**运气七篇 7/7**（另有阴阳应象大论等 4 篇），标志字 化↑ 火↑ 太↑ 脉↓，p = 0.025；最强的变点在第 65、66 篇之间，另一变点在第 74、75 篇之间——正是七篇的起止（均 p = 0.005；另有几处较弱的变点）；晚出词汇标出至真要大论（z = 4.26）、五常政大论、六元正纪大论；伤寒论的辨脉法、平脉法最近《脉经》（传统归于王叔和） |

| **医理论证** `study argument` | 分句（并在句内“则”“故”前切分），按标记表连成有类型、有方向的边：条件、结果、原因/所致、推断、补充理由、转折、取象比类、驳斥、界说、主治；只用明确标记，不猜测省略的推理；一部书的论证画像与两书比较（JSD、对数几率） | 伤寒论 vs 温热论：关系分布 JSD 0.063；伤寒论多界说与推断，温热论多取象比类（每千句 7.76 对 0）与驳斥，条件与主治更多 |

| **佚书辑佚** `study fragments` | 识别《外台秘要》式出处（小品论曰……（出第十卷中千金同））、“又”承上、《某书》云，截取至出处注或下一出处，保留卷次与互见，合并重出，按卷次排序；早于该书的引书排除；在存世书上验证方法，得到各引书的可信度 | 小品方：由 190 次引用辑得 132 条，其中 90 条见于库中的今人辑校本；以千金要方验证：辑文在存世本中的比例 0.32（幼幼新书 0.83、外台 0.55、医心方 0.36），覆盖 12%；肘后备急方 87.6% 的引文不见于今本——今本经陶弘景增补、杨用道附广，这些正是辑佚的候选佚文 |

（来源、逐字、校勘、义项、抽取、独立来源、时间、专家、现代证据）→ 发现分数 `D = w1·E + w2·N + w3·R + w4·T + w5·F − w6·A`
（始终与分量一起报告）→ 置信向量（文本、训诂、语义、抽取、跨源、时间、统计、现代映射；现代生物医学有效性默认 **unknown**）。
历史术语与现代概念之间只能是带类型的映射（related / partially_overlapping / uncertain / not_equivalent），只有人类专家能认定“等价”。

### 设计原则

| 原则 | 在代码中的体现 |
|---|---|
| **Deterministic Harness, Stochastic Intelligence** | 内核（事件溯源、事务、门控、停止条件）完全确定；模型只在需要判断的角色中出现，其输出必须通过模式校验与逐字核验 |
| **Everything is a Plugin** | 语料、领域包、检索、治学、模型、沙箱、存储都是插件；模式挖掘、统计与治学是工具优先的确定性过程 |
| **Claims, not facts** | 主张是“某书某版某处这样说”的超边，而非脱离语境的医学事实 |
| **No forced single reading** | 有异文之处保留各读法的概率和“不确定”质量 |
| **No medical anachronism** | 古今概念只有带类型的映射；“等价”只能由专家认定 |
| **Propose, don't commit** | 智能体只能提议修改规范知识；校验器或人类决定 |
| **Evidence-first** | 没有逐字证据的结论不会写入；伪造或改写的引文被机械核验拦截 |
| **The harness decides when to stop** | 证据饱和、无新来源、门控通过、预算耗尽或需专家介入——由内核判断 |

## 六、使用场景

**研究者**

- *一首方的源流*：`study formula 肾气丸` → 原方（《金匮要略》崔氏八味丸）、通行方、同方异名（桂附地黄丸/汤）、各本剂量比例、
  历代主治与加减；`--json` 或 `study dataset --formula 肾气丸` 得到逐条见证表，做进一步统计。
- *一味药的性能演变*：`study herb 附子` → 本经“温、有毒”，《证类本草》“大毒”，《汤液本草》“大热、阳中之阳”，
  归经之说在所收本草中首见于清初《本草择要纲目》（手少阳、足少阴、三焦、命门）——每一变化都给出首见之书、年代与原文。
- *一个概念的历史语义*：`study term 中风` → 分期频率与趋势、各期搭配（明代语境中“半身不遂”“拘急”突出）、历史义项；
  再以 `research … --focus 中风 --forbid 中风=脑卒中` 做可证伪的概念演变研究。
- *一部书的版本*：`study taboo <book_id>` → 讳例计数与版本年代下限；与 `study concordance` 的同书异本比对互为印证。
- *学术传承*：`study citations` 看各期宗主；`study citations 李杲` 看东垣学说的接受史。
- *一部书的版本谱系*：`study stemma 伤寒论` → 各本的异文单元、谱系树、共同异文分组与污染；`study tei` 导出 TEI 校勘记，
  `study edition <book_id>` 看某一本与其他各本的一致率、独有异文、缺文与增文。
- *一部书有哪些本子可读、可看*：`study witnesses 伤寒论` → 库中各录本的底本、年代、藏所、来源与授权（CMETA 本的段落可直接打开所据页面的
  影像），以及各馆数字化的刻本与抄本（年代、刻/写、藏所、索书号、IIIF 清单、授权），按年代排列。
- *一段经文的接受史*：`study reuse <经文>` → 后世逐条的复用类型与判定规则（谁照录、谁节略、谁改写解释、谁引而驳之）；
  `study transmission 伤寒论` 看一部书各时代被保留、改造、争议的比例与传播渠道。
- *一部经典的成书层次*：`study layers 素问` 与 `study dating 素问` 并读——文风说明篇章“不同”，引书、晚出词汇与避讳说明它们
  “可能何时写成”；`study authorship` 以 Burrows' Delta 比较候选作者。
- *医案研究*：`study cases --book <id>` 逐诊读出四诊、治法、方药加减与转归；`study trajectories 咳嗽` 看历代医家的诊疗序列
  （记录中的关联，不是疗效证据）。
- *辑佚*：`study fragments 小品方` 辑出佚文并注明每条的引书与卷次；`--verify` 先在存世书上检验方法与各引书的可信度。
- *可复现发表*：数据包带语料指纹（书数、段数、来源、规范化版本、目录摘要），同一语料上重算结果一致。

**学生与自学者**

- `study cards --book 伤寒论 --anki shl.tsv`：伤寒论全部“……者，某方主之”的方证填空卡，导入 Anki 间隔复习；
- `study cards --formula 桂枝汤 --formula 小柴胡汤`：组成、剂量、炮制、煎服法，附方歌；
- `study cards --herb 柴胡 --herb 附子`：本经与后世本草的性味归经对照；
- `study reading 温病`：从素问、伤寒到温病条辨的阅读门径，每部书写明为什么读；
- `study concordance`：读到一句经文，看它在历代被谁引用、怎样改写。
- `study argument "<一段经文>"`：看一段条文怎样推理——条件、推断、因果、转折、取象比类、驳斥、界说、主治逐条标出；
  `study senses 消渴`：看一个词在各时代的义项与变迁。

## 七、模型与部署

默认完全离线：所有智能体都有确定性过程（procedure），治学层不需要模型。判断型角色可以走模型：

```bash
pip install -e ".[anthropic]"
export ANTHROPIC_API_KEY=...
taochronos demo --profile claude   # Opus 5（前沿层）/ Sonnet 5（中层）/ Haiku 4.5（小层）
```

Claude 提供者默认开启服务端拒答回退（`fallbacks="default"`，适用于 Opus 5）；若模型拒答、输出无法通过模式校验或预算耗尽，
该任务回退到确定性过程，并把回退记录为一条 Decision。也支持 OpenAI 兼容端点（DeepSeek、Grok、Gemini、本地 vLLM/Ollama）、
外部命令子智能体与 Research Code Mode，见 [docs/agents.md](docs/agents.md)。

## 八、评测与质量保证

`taochronos eval` 在演示语料上运行（约两分钟；有全量语料时，深层发现 2.0 的套件同时在真实语料上核查）。金标准由作者为演示语料构建并在开发中使用，**只作回归测试，不是无偏基准**
（见 [evals/gold/README.md](evals/gold/README.md)）。

| 套件 | 结果 |
|---|---|
| Philology | 7/7：不强行定读、保留不确定质量、规范化匹配 |
| Claims | P 0.98 · R 0.95 · F1 0.96；抽取主张 100% 逐字可核 |
| Provenance | 主张与证据 100% 逐字；平均溯源链 7.8 层（演示语料无页面图像，页/行/区域/图像层如实标为不可用） |
| Hallucination | 伪造与单字篡改引文 100% 检出；真实引文与合法异体写法不误报 |
| Contradiction | 12/12（含鉴别诊断、文本承袭等难负例） |
| Lineage | P 0.87 · R 0.93（逍遥散、补阳还五汤两条组成相似的伪谱系） |
| Temporal | 时代约束 6/6、最早出处 6/6、时代泄漏 0 |
| Anachronism | 10/10 陈述、8/8 映射；智能体断言“等价”被拦截 |
| Recovery | 4/4 崩溃点恢复后科学状态哈希一致；并行 = 串行；重放一致 |
| Time Machine（1368） | 可判定预测 2/3 成立；零泄漏 |
| Source rediscovery | 素问/灵枢/伤寒论逐一留出后 3/3 被重新推断，年代下限一致 |
| Ablations | 去义项路由：最早出处 0.67；去义项消歧：矛盾 0.83；Context OS 令上下文 −94%；关闭质疑者：1 个伪假说存活 |
| Collation | 按已知谱系人工传抄的 5 个传统：异文单元召回 0.998、精确 0.999；真实分支每次都找回；前三分组全部正确；污染 P/R 1.0 |
| Reuse | 33 对开发集：准确率 0.97、宏 F1 0.965；复用检出 P 1.0 · R 0.96 |
| Stratigraphy | 合成拼合文本：分层准确率 0.955、层界召回 0.90 / 精确 0.93、作者归属 0.89；真实：运气七篇 7/7、起止变点 2/2、叔和二篇 2/2 |
| Cases | 开发集各项 1.0；真实：吴鞠通医案两录本病案数一致 0.98、转归 0.92 |
| Argument | 开发集边 F1 1.0；真实：同书两录本 JSD 0.020，对他书 0.091 |
| Senses | 合成义项转移：变点年误差 2.3 年、标注准确率 0.93、隐藏义项找回 1.0；策展例句 6/8 |
| Fragments | 构造语料：精确 0.86、覆盖 1.0、他书文字误入 0；真实：千金 0.32 / 0.12，肘后 87.6% 引文不见今本 |

深层发现 2.0 的开发集与规则一起写成，数值说明规则“打算做什么”，不代表泛化能力；全量语料上的专家金标准列入路线图。

另有 159 个单元与集成测试（`pytest`，含各来源格式样例与一个为治学层编写的合成语料 `tests/fixtures/study`），
以及架构治理检查（`taochronos governance`：分层依赖、内核中立、模型 SDK 隔离、智能体规则）。CI 在 Python 3.11/3.12 上运行治理、测试、
快速评测与演示研究。

## 十二、局限

- 语料未经本项目逐字校勘：四库本有清人删改与避讳改字，白文断句为规则式；笈成本为志愿者录入，品质不一；断代在无人工考定时
  依据书籍信息与序跋落款，无从考定者只能保守定为“清代或更早”。
- 治学层与抽取器是规则式的机器阅读：方剂组成、本草条目与性能靠模式与词表读取，词表缺漏会使组成不全；只有一条见证的
  “孤例”与不常见的版式需要人工核对。所有输出都附原文，便于核查。
- 注本中未分层的后人按语随正文断代：早于被引者的引用会被识别并另计，但与正文同期或更早的引文（如孙星衍辑本《本经》按语引《说文》）
  仍计入正文时期。
- 度量衡数值、讳例起始年与医家生卒是有出处的学术观点，可能有争议，均为可审阅的 YAML；避讳证据只说明版本年代下限，属提示性证据。
- 去重按文本重合度判定，同一版本的两个录本与不同版本之间的界线并不绝对；被判为副本的书逐部记录，可以人工改判。
- 演示语料很小（23 部书、131 段节录），评测数值只具说明意义；Time Machine 与链接预测需要大规模语料才有统计意义。
- 深层发现 2.0 同样是规则式的：谱系树是对库中几个录本关系的假设，污染标记要人去核查；复用规则的阈值定在 33 对开发集上，
  词表之外的概念只能凭文字找到；文风会随题材变化（运气诸篇讲的就是运气），文风与断代证据单独都不能证明后增；医案解析按几种
  医案体例编写，其他体例可能切错病案；只有明确标记才成为论证边；候选新义只是语境词聚类，要人读例句后才算义项；辑文的可信度
  以各引书在存世书上的验证精确率为准。
- 影像见证按题名关联到库中著作：注释书与同名异书单凭题名无法区分，关联要人去核对；只收书目元数据，不下载影像，
  年代以各馆著录为准（只有年号的按该年号的起讫计）。
- 系统不提供医学建议；任何研究结论在专家（Gate G7）核验前都只是研究线索。
